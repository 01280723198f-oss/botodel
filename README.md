# 🤖 Ботодел

Скилл для Claude Code: Claude сам собирает тебе Telegram-ботов и панель управления ими,
как у конструкторов ботов, только на твоём Маке и без подписки.

- 📊 Дашборд: люди в базе, новые за неделю, старты по дням
- 👥 Подписчики из всех ботов в одной таблице с поиском
- 🤖 Боты и сценарии со статусом «онлайн», сколько стартовали и дошли до конца
- 📈 Источники: метки `?start=` — откуда пришли люди, ссылки в один клик
- ✉️ Рассылки: тест себе → проверил → всем (без теста «всем» не отправить)
- 📣 Число подписчиков канала
- 📱 Доступ с телефона по ссылке с ключом, 🖱 ярлык в Доке

## Установка

В Claude Code по очереди:

```
/plugin marketplace add 01280723198f-oss/botodel
/plugin install botodel@botodel
```

Перезапусти Claude Code и напиши:

- «Сделай мне панель Ботодел для моих ботов» — если боты уже есть;
- «Собери мне Telegram-бота: [что он делает] — и подключи в Ботодел» — если ботов ещё нет.

Claude найдёт ботов, покажет, что попадёт в панель, соберёт и проверит.
Автозапуск и ярлык в Доке он попросит подтвердить.

<details><summary>Без плагинов, через терминал</summary>

```bash
git clone --depth 1 https://github.com/01280723198f-oss/botodel /tmp/botodel \
  && mkdir -p ~/.claude/skills && cp -R /tmp/botodel/plugins/botodel/skills/ботодел ~/.claude/skills/ \
  && rm -rf /tmp/botodel
```
</details>

## Что нужно

- macOS, Python 3 (есть в системе), Claude Code
- Токен бота от @BotFather — Claude подскажет, где взять
- Для числа подписчиков канала бот должен быть админом канала

Панель откроется на http://127.0.0.1:8795

## Безопасность

Базы ботов панель читает только на чтение. Токены не попадают на страницу.
С телефона — только по ссылке с ключом. Рассылку делает сам бот своей командой.
