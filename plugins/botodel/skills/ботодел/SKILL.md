# Ботодел: боты на Claude + панель управления

Две части. **Бот** — Claude пишет его сам (Python stdlib, long polling, SQLite, launchd).
**Панель** — один файл `panel.py` + страница `panel.html`, читает базы ботов только на чтение
и умеет одно действие: рассылку, которую делает сам бот своей командой.

Боты живут на Маке через launchd. Панель — тоже. Ничего не арендуем, ключей наружу не отдаём.

## Порядок работы

### 1. Инвентаризация (до любого кода)
Найди, что уже есть: `launchctl list | grep -v com.apple`, папки ботов, `*.sqlite`, токены в
`~/.claude/secrets/*.env`. Раздели ботов на два вида:
- **для подписчиков** — собирают людей в базу (подарок, анкета, уникализатор, запись) → карточка
  с числом людей, сценарии, рассылка;
- **рабочие** — пульт Claude, агенты, задачи по расписанию → только «онлайн / ждёт / ошибка».

Покажи пользователю список и что попадёт в панель. Чужие боты (клиентов, других людей
в той же системе) в панель не добавляй без явной просьбы.

### 2. Новый бот (если нужен)
- Если установлен скилл **`бот-подарок`** и нужен подарок за подписку — бери его шасси.
- Иначе (и для любого другого бота) пиши сам по контракту `references/bot-contract.md`: таблицы
  `users / starts / broadcasts`, метка источника из `?start=`, команда `--broadcast FILE [--test]`,
  токен в `~/.claude/secrets/<имя>.env`, запуск launchd из папки **вне** Рабочего стола и
  Документов (иначе macOS: `Operation not permitted`). Оффлайн-тест до запуска.

Бот по контракту появится в панели сам — без правки кода панели.

### 3. Панель
1. Скопируй `scripts/bots.example.json` → `~/.bots-panel/bots.json`, впиши ботов:
   - `audience[]`: `id`, `kind` (`gift` — шасси бота-подарка: сценарии из `gifts.json`,
     цепочка из `drip.json`, источники с пригласительными ссылками; `uniq` — бот с таблицей
     `jobs` и кнопкой в рассылке; `basic` — любой бот по контракту), `title`, `dir` (папка с
     `bot.py` и `bot.sqlite`), `env` + `token` (имя файла в секретнице и переменной), `launchd`.
   - `service[]`: `id`, `title`, `launchd`, `what`, `job: true` для задач по расписанию.
   - `channel`: `username` канала и `via_bot` — бот-админ канала (им берётся число подписчиков).
   - `sources`: человеческие названия своих меток (`"insta": "Instagram"`).
2. Проверка без сервера: `python3 scripts/panel.py --dump` с `BOTS_PANEL_CONFIG=путь/bots.json`
   — цифры должны совпасть с `sqlite3 <база> "select count(*) from users"`.
3. Автозапуск: `scripts/install.sh ~/.bots-panel/bots.json` (копирует в `~/.bots-panel`,
   ставит launchd `com.<user>.bots-panel`). Ярлык в Док: `scripts/make_app.sh`.
   Установку launchd и Дока делает пользователь сам или подтверждает — это постоянные изменения Мака.
4. Открой `http://127.0.0.1:8795`, сними скрины разделов headless-Chrome и посмотри глазами.

### 4. Сдача
Покажи: где панель, что в каждом разделе, какие боты онлайн, что нашлось по дороге
(падающие задачи — смотри `LastExitStatus` в `launchctl list <label>` и их логи).

## Безопасность (не ослаблять)
- Базы открываются `mode=ro`. Панель не пишет в боты, кроме запуска их собственной `--broadcast`.
- «Всем» сервер пропускает только после успешного теста **того же** текста тем же ботом;
  одна массовая рассылка за раз; в интерфейсе — подтверждение с числом получателей.
- Слушает Wi-Fi для телефона, но всё, кроме `/` с самого Мака, требует ключ `?k=` (файл `.key`
  рядом с panel.py, 0600). Заголовок Host проверяется (защита от DNS rebinding).
- Токены в страницу и ответы API не попадают; @имена ботов кешируются в `cache.json`.
- `.key` и `cache.json` в `.gitignore`.

## Грабли
- launchd + файл на Рабочем столе → `Operation not permitted` и бесконечный перезапуск. Всегда копия в `~/.bots-panel`.
- Задачи по расписанию на Маке в 21:00 часто без сети (сон, VPN): отчёты оборачивай в повторы
  (6 × 5 мин на `OSError`), иначе они молча падают неделями.
- У живого бота может быть свой `gifts.json`, отличный от копии в проекте: панель читает файлы
  из `dir` работающего бота — показывает то, что реально крутится.
- Автообновление страницы раз в 30 с не должно стирать черновик рассылки: на вкладке
  «Рассылки» обновляется только история.

## Файлы
- `scripts/panel.py` — сервер (stdlib), `--dump` для проверки.
- `scripts/panel.html` — страница: Дашборд, Подписчики, Боты, Источники, Рассылки.
- `scripts/bots.example.json` — пример настроек.
- `scripts/install.sh`, `scripts/open.sh`, `scripts/make_app.sh`, `scripts/icon.icns` — автозапуск и ярлык.
- `references/bot-contract.md` — что должен уметь бот, чтобы панель его видела.
